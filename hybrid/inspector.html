1 · What the robot observes

Move a slider or enter a value. Each change reruns the same trained SNN; it does not retrain or move the robot.

Coordinates follow the direction toward the goal, not the robot’s body heading. Negative clearance means overlap with the planning footprint.

How to interpret these experiments

These are interventions on the network’s input vector. Editing one derived clearance independently may describe an impossible physical scene. The UI does not rerun geometry or simulate a new trajectory. Safety checks below apply the real mask thresholds to the supplied clearances.

Weights stay frozen. Normalized inputs are clipped to ±5. Beyond that range, moving a value farther will not change the network input. Results explain this model locally, not real-world causality or general feature importance.

2 · Decision and safety constraints

Observations → 64 spiking neurons → 32 spiking neurons → 4 scores → safety mask → skill → gait + PID

Scores are not probabilities. The supervisor selects the highest-scoring allowed skill. If every skill is masked, no skill is available.

4 · Inside this decision’s 16 steps

Spike raster

Membrane before and after reset

Each decision starts at zero. Membrane = 0.9 × previous value + input current. At ≥1, a neuron emits one spike and subtracts 1. Membrane values are dimensionless, not biological voltages. Internal steps are not seconds. The SNN runs at skill-selection events; PID continues between them.
