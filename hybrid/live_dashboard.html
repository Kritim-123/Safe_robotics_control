Geometry and prediction limits

Boxes are enclosed by circles for the existing planner. This is conservative and can reject feasible narrow passages. Motion prediction uses current velocity, so a reversing barrier can invalidate that prediction. The skills go around or wait; they do not jump or climb.

07 / Which inputs matter here?

Captured at selection time. Sensitivity changes one input by ±0.25 training standard deviations, with others held fixed; it ranks the largest resulting absolute score change. This analysis never changes the robot’s action.

Interpreting input effects

Finite perturbations are local experiments, not percentages of responsibility. Some edited feature combinations may be geometrically impossible. Zero sensitivity can mean that no spike threshold was crossed, or that input normalization clipped the value. Use the separate inspector to edit values interactively.
