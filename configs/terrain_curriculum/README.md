# Terrain curriculum snapshots

These 60 editable MuJoCo scenario configurations were generated by
`experiments.spike_pattern_skills.curriculum.curriculum(seed=20261017)`.
Names contain level, environment family and variant. Levels run from 00 to 09;
variants run from 00 to 05. Units are metres, seconds and radians; friction is
dimensionless. Box sizes are **half extents**. Ramp height is the rise over
twice its first half extent, before yaw rotation.

Variants 0-2 are development, 3 validation, 4-5 held out; severity increases
within each non-flat family. The six flat configurations intentionally repeat
the same physical reference. These snapshots match the audited curriculum
benchmark. If editing them, save a separate version and record its provenance;
the curriculum runner normally generates its scenes from the fixed seed.

Use `Scenario.load(path)` to load an individual configuration. The runner,
progression gates, actual results and limitations are documented in
`docs/agents/terrain_curriculum_validation.md`. Terrain entries are static
walkable support surfaces; obstacles are hazards. The original floor remains
underneath, so these configurations do not contain gaps or pits.
